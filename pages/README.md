### View entity details (Site, Environment, Exchange)

#### Workspace section

Workspace attributes are displayed in 4 columns

#### Configurations section

List of configurations from current entity plus configurations from parent entities.

The list is sorted in hierarchy mode so that the current entity is on top.

#### Sub-entities section with tabs

Each tab will show the list of sub-entities.

A list of action buttons will be available above the list.

### View entity details (Service)&#x20;

#### Service details

Service attributes are displayed in 4 columns

#### Configurations section

List of configurations from current entity plus configurations from parent entities which are relevant for the current service (depending on the configuration file).

The list is sorted in hierarchy mode so that the current entity is on top.

### Add entity (Site, Environment, Exchange)

For these entities will be used a wizard of 4 steps:

1. General details
   1. Entity details
   2. Resources
2. Add services
3. Add configurations
4. Review and create
