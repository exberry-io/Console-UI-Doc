# Environment details

**Page title**: ENV\_NAME

**Action buttons**

* More - expandable
  * Clone
  * Dispose
* Deploy

**Workspace container**

See [workspace container](../containers.md#workspace-details) details.

**Configurations container** in read-only mode

**Tabs with sub-entities**

* Exchanges list with&#x20;
  * "Add" action button - which opens the Add Exchange wizard
  * "View all" link - which opens the list in a new page
* Services list with&#x20;
  * "Add" action button - which opens the Add Service page
  * "View all" link - which opens the list in a new page
* Resources list with&#x20;
  * "Link" action button - which opens the "Link resource" popup
  * "View all" link - which opens the list in a new page
