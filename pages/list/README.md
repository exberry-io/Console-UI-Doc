# List

## General

This type of page is displayed when we need to show a list of records in full width of the page.

### Components

#### **Table component**&#x20;

It has the basic features of the table (column sorting, pagination, filters).

Single select is allowed.

**Action buttons**

List of buttons is described for each case (see sub-pages).

**Split panel**

See sub-pages for details.
